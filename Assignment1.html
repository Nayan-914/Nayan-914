Database Management Systems & C Programming Guide

Database Management System

What is DBMS?

A Database is an organized collection of structured data stored electronically in a computer system.

A DBMS (Database Management System) is software that interacts with users, applications, and the database itself to capture and analyze data.

Advantages of DBMS:

  • Data sharing among multiple users
  • Reduced data redundancy
  • Data integrity and security
  • Concurrent access control
  • Backup and recovery features
  • Data independence

Disadvantages of DBMS:

  • High initial setup cost
  • Complexity in design and implementation
  • Performance overhead
  • Need for specialized personnel (DBA)
  • Vulnerability to failures

File Processing System vs DBMS

File Processing System DBMS
Data is stored in separate files Data is stored in a structured format
High data redundancy Minimal data redundancy
No data integrity constraints Supports data integrity constraints

DBMS Models

Model Advantages Disadvantages

Object-Oriented Handles complex data types, supports inheritance Not as mature as relational, steep learning curve

Relational Database

A relational database organizes data into tables (relations) with rows and columns, where relationships between tables are established using keys.

Differences from other models:

  • Uses tables instead of trees (hierarchical) or graphs (network)
  • Data is stored in a structured format with strict schema
  • Relationships are logical rather than physical pointers
  • Uses SQL for querying
  • Supports ACID properties (Atomicity, Consistency, Isolation, Durability)

Data Redundancy

Data redundancy occurs when the same piece of data is stored in multiple places.

How DBMS reduces redundancy:

  • Normalization process eliminates duplicate data
  • Foreign keys create relationships instead of duplicating data
  • Centralized storage ensures single source of truth
  • Views can present data from multiple tables without storing it redundantly

Database Administrator (DBA)

A professional responsible for managing, maintaining, and securing databases.

Major responsibilities:

  • Database design and implementation
  • Performance monitoring and tuning
  • Backup and recovery planning
  • User access management and security
  • Data integrity enforcement
  • Capacity planning
  • Troubleshooting database issues
  • Implementing new database technologies

Normalization Process

Normalization is the process of organizing data in a database to reduce redundancy and improve data integrity.

1NF (First Normal Form):

  • Each table cell should contain a single value
  • Each record needs to be unique
Students table (before 1NF):
ID | Name       | Subjects
1  | Monkey D. Luffy | Math, Science

After 1NF:
ID | Name       | Subject
1  | Monkey D. Luffy | Math
1  | Monkey D. Luffy | Science

2NF (Second Normal Form):

  • Must be in 1NF
  • All non-key attributes must depend on the entire primary key
StudentSubjects table (before 2NF):
StudentID | Subject | Teacher | TeacherDepartment
1         | Math    | Kizaru  | Science

After 2NF:
StudentSubjects:
StudentID | Subject
1         | Math

Teachers:
Teacher | TeacherDepartment
Kizaru  | Science

3NF (Third Normal Form):

  • Must be in 2NF
  • No transitive dependencies
Students table (before 3NF):
ID | Name       | Crew | CrewShip
1  | Monkey D. Luffy | Straw Hats | Thousand Sunny

After 3NF:
Students:
ID | Name       | CrewID
1  | Monkey D. Luffy | 1

Crews:
CrewID | CrewName  | Ship
1      | Straw Hats | Thousand Sunny

SQL Keys

Primary Key:

A column or set of columns that uniquely identifies each row in a table.

Example: In a Pirates table, PirateID could be the primary key.

Foreign Key:

A column that creates a relationship between two tables by referencing the primary key of another table.

Example: In a CrewMembers table, PirateID would be a foreign key referencing the Pirates table.

Candidate Key:

A column or set of columns that could serve as a primary key (all unique and not null).

Example: In a Pirates table, both PirateID and PirateName (if unique) could be candidate keys.

SQL Components

SQL (Structured Query Language) is a standard language for managing and manipulating relational databases.

Components of SQL:

  1. DDL (Data Definition Language): CREATE, ALTER, DROP
  2. DML (Data Manipulation Language): SELECT, INSERT, UPDATE, DELETE
  3. DCL (Data Control Language): GRANT, REVOKE
  4. TCL (Transaction Control Language): COMMIT, ROLLBACK

Common SQL Functions:

  • Aggregate: COUNT(), SUM(), AVG(), MAX(), MIN()
  • String: CONCAT(), SUBSTRING(), UPPER(), LOWER()
  • Date: NOW(), DATE(), YEAR(), MONTH()
  • Mathematical: ROUND(), ABS(), RAND()

Example SQL Commands:

CREATE TABLE pirates (
    pirate_id INT PRIMARY KEY,
    name VARCHAR(50),
    bounty BIGINT,
    crew VARCHAR(50)
);

INSERT INTO pirates VALUES 
(1, 'Monkey D. Luffy', 3000000000, 'Straw Hats'),
(2, 'Roronoa Zoro', 1111000000, 'Straw Hats');

SELECT * FROM pirates WHERE bounty > 1000000000;

C Programming Concepts

Functions in C

A function is a self-contained block of code that performs a specific task.

Function Syntax:

return_type function_name(parameters) {
    // function body
    return value; // if return_type is not void
}

Types of functions:

  • Library functions (e.g., printf(), scanf())
  • User-defined functions (created by programmers)

Components of function:

  1. Function prototype: Declaration of function (e.g., `int add(int a, int b);`)
  2. Function call: Using the function in code (e.g., `sum = add(5, 3);`)
  3. Function definition: Implementation of function
  4. Return type: Data type of value returned (void if no return)

Function Categories with Examples:

// 1. Function with return type but no arguments
int getBounty() {
    return 1500000000; // Luffy's bounty
}

// 2. Function with return type with arguments
int addBounty(int current, int increase) {
    return current + increase;
}

// 3. Function with no return type with no arguments
void shoutLuffy() {
    printf("I'm Monkey D. Luffy! The man who will be Pirate King!\n");
}

// 4. Function with no return type with arguments
void displayCrew(char name[], char role[]) {
    printf("%s is the %s of the Straw Hat crew.\n", name, role);
}

Storage Classes in C

Automatic (auto):

Default for local variables, exists only within its block

void devilFruit() {
    auto int power = 1; // automatic variable
}

External (extern):

Variables declared outside functions, visible to all files

extern int crewMembers; // declared in another file

Register:

Suggests compiler to store in register for faster access

register int speed = 3; // like Sanji's speed

Static:

Preserves value between function calls, initialized only once

void countHakiUses() {
    static int count = 0; // retains value between calls
    count++;
    printf("Haki used %d times\n", count);
}

Recursive Functions

A recursive function is one that calls itself directly or indirectly.

Syntax:

return_type function(parameters) {
    if(base_condition) {
        return base_value;
    }
    else {
        // modify parameters
        return function(modified_parameters);
    }
}

Example 1: Calculating bounty increase recursively

int calculateBounty(int years) {
    if(years == 0) {
        return 30000000; // initial bounty
    }
    else {
        return 2 * calculateBounty(years - 1);
    }
}

// Usage: int luffyBounty = calculateBounty(3); // returns 240000000

Example 2: Finding Devil Fruit powers

void devilFruitPowers(int level) {
    if(level <= 0) {
        printf("No power awakened.\n");
        return;
    }
    printf("Awakening level %d power!\n", level);
    devilFruitPowers(level - 1);
}

// Usage: devilFruitPowers(5);
