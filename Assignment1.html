Database Management System

What is DBMS?

A Database is an organized collection of structured data stored electronically in a computer system.

A DBMS (Database Management System) is software that interacts with users, applications, and the database itself to capture and analyze data.

Advantages of DBMS:

  • Data sharing among multiple users
  • Reduced data redundancy
  • Data integrity and security
  • Concurrent access control
  • Backup and recovery features
  • Data independence

Disadvantages of DBMS:

  • High initial setup cost
  • Complexity in design and implementation
  • Performance overhead
  • Need for specialized personnel (DBA)
  • Vulnerability to failures

Relational Database

A relational database organizes data into tables (relations) with rows and columns, where relationships between tables are established using keys.

Differences from other models:

  • Uses tables instead of trees (hierarchical) or graphs (network)
  • Data is stored in a structured format with strict schema
  • Relationships are logical rather than physical pointers
  • Uses SQL for querying
  • Supports ACID properties (Atomicity, Consistency, Isolation, Durability)

Data Redundancy

Data redundancy occurs when the same piece of data is stored in multiple places.

How DBMS reduces redundancy:

  • Normalization process eliminates duplicate data
  • Foreign keys create relationships instead of duplicating data
  • Centralized storage ensures single source of truth
  • Views can present data from multiple tables without storing it redundantly

Database Administrator (DBA)

A professional responsible for managing, maintaining, and securing databases.

Major responsibilities:

  • Database design and implementation
  • Performance monitoring and tuning
  • Backup and recovery planning
  • User access management and security
  • Data integrity enforcement
  • Capacity planning
  • Troubleshooting database issues
  • Implementing new database technologies

Normalization Process

Normalization is the process of organizing data in a database to reduce redundancy and improve data integrity.

1NF (First Normal Form):

  • Each table cell should contain a single value
  • Each record needs to be unique

Primary Key:

A column or set of columns that uniquely identifies each row in a table.

Example: In a Pirates table, PirateID could be the primary key.

Foreign Key:

A column that creates a relationship between two tables by referencing the primary key of another table.

Example: In a CrewMembers table, PirateID would be a foreign key referencing the Pirates table.

Candidate Key:

A column or set of columns that could serve as a primary key (all unique and not null).

Example: In a Pirates table, both PirateID and PirateName (if unique) could be candidate keys.

SQL Components

SQL (Structured Query Language) is a standard language for managing and manipulating relational databases.

Components of SQL:

  1. DDL (Data Definition Language): CREATE, ALTER, DROP
  2. DML (Data Manipulation Language): SELECT, INSERT, UPDATE, DELETE
  3. DCL (Data Control Language): GRANT, REVOKE
  4. TCL (Transaction Control Language): COMMIT, ROLLBACK

Common SQL Functions:

  • Aggregate: COUNT(), SUM(), AVG(), MAX(), MIN()
  • String: CONCAT(), SUBSTRING(), UPPER(), LOWER()
  • Date: NOW(), DATE(), YEAR(), MONTH()
  • Mathematical: ROUND(), ABS(), RAND()
