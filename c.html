1. Working with a Function

a. Define Function

Q: What is a function in C?
A: A function is a self-contained block of code that performs a specific task. Functions enhance modularity and reusability in programs.

b. Syntax of a Function

return_type function_name(parameter_list) {
    // body of the function
}

c. Types of Functions

  • Library functions: Predefined functions such as printf(), scanf(), sqrt(), etc.
  • User-defined functions: Functions created by the programmer to perform specific tasks.

d. Components of a Function

  1. Function Prototype: Declares the function before main().
    int add(int, int);
  2. Function Call: Invokes the function.
    add(5, 7);
  3. Function Definition: Actual body of the function.
    int add(int a, int b) {
    return a + b;
}
  4. Return Type: Specifies the type of value returned by the function (e.g., int, void, float).

2. Categories of Functions with Examples

i. Function with Return Type but No Arguments

Q: What does it mean?
A: The function returns a value but takes no parameters.

    printf("Naruto's age is: %d\n", age);
    printf("The program is executed by Nayan Kumar Gautam\n");
    return 0;
}

int getAge() {
    return 17;
}

ii. Function with Return Type and with Arguments

#include <stdio.h>

int power(int base, int exponent);

int main() {
    printf("Sasuke's chakra power: %d\n", power(2, 4));
    printf("The program is executed by Nayan Kumar Gautam\n");
    return 0;
}

int power(int base, int exponent) {
    int result = 1;
    for (int i = 0; i < exponent; i++)
        result *= base;
    return result;
}

3. Storage Classes in C

Storage Class Description Keyword
Automatic Default in local scope auto
External Global scope variables extern
Register Stores in CPU register register
Static Retains value between calls static

Example: Static Storage Class

#include <stdio.h>

void countCalls();

int main() {
    countCalls();
    countCalls();
    countCalls();
    printf("The program is executed by Nayan Kumar Gautam\n");
    return 0;
}

void countCalls() {
    static int count = 0;
    count++;
    printf("Hinata called this %d time(s)\n", count);
}

4. Recursive Function

Q: What is recursion?
A: Recursion is when a function calls itself to solve a smaller instance of the same problem.

Example: Factorial using Recursion (Neji’s Computation)

#include <stdio.h>

int factorial(int n);

int main() {
    int num = 5;
    printf("Neji's factorial of %d is: %d\n", num, factorial(num));
    printf("The program is executed by Nayan Kumar Gautam\n");
    return 0;
}

int factorial(int n) {
    if (n == 0)
        return 1;
    else
        return n * factorial(n - 1);
}

6. Additional Notes & Examples

Function with Multiple Arguments and Return Value

#include <stdio.h>

int max(int a, int b, int c);

int main() {
    printf("The strongest in Team 7 is: %d\n", max(100, 95, 110));
    printf("The program is executed by Nayan Kumar Gautam\n");
    return 0;
}

int max(int a, int b, int c) {
    int m = a;
    if (b > m) m = b;
    if (c > m) m = c;
    return m;
}

Inline Function (Conceptual in C99+)

C does not support true inline functions like C++, but you can use the inline keyword in C99 and above for optimization hints. 
#include <stdio.h>

inline int square(int x) { return x * x; }

int main() {
    printf("Naruto's shadow clone squared: %d\n", square(9));
    printf("The program is executed by Nayan Kumar Gautam\n");
    return 0;
