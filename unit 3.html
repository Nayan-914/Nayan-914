Chapter 3:Software and Operating Systems

3.1 Concept of Software

3.1.1 Definition of Software

Software is the non-tangible component of a computer system, consisting of instructions and data that tell the hardware what to do. It's written in programming languages and translated into machine code. Software enables computers to perform a wide array of tasks, from simple calculations to complex operations.

3.1.2 Categories of Software

  • System Software: Manages hardware and provides a platform for other software. Examples include operating systems (Windows, macOS, Linux), device drivers, and system utilities. System software is crucial for resource allocation and security.
  • Utility Software: Performs maintenance and optimization tasks. Examples include antivirus software, disk defragmenters, file compression tools, and backup utilities. Utility software enhances performance and prevents data loss.
  • Application Software: Helps users perform specific tasks. Examples include word processors (Microsoft Word), web browsers (Chrome, Firefox), graphic design software (Photoshop), and games. Application software enhances productivity, creativity, and entertainment.
  • Web-Based Software: Runs on web servers and is accessed via browsers. Examples include Gmail, Google Docs, and online banking platforms. Cloud computing and SaaS (Software as a Service) are prominent examples of web-based software.
  • Mobile Apps: Designed specifically for smartphones and tablets. Examples include WhatsApp, Instagram, and mobile banking apps. Mobile apps often interact with device hardware like GPS and cameras.

3.2 Concept of Operating System

3.2.1 Introduction to Operating System

An operating system (OS) is essential system software that manages computer hardware, software resources, and provides services for applications. The kernel is the core of the OS, handling fundamental operations.

3.2.2 Role of Operating System

  • Manages hardware resources like CPU, memory, and I/O devices, preventing programs from interfering with each other.
  • Provides a user interface (GUI or CLI) to interact with the computer.
  • Facilitates multitasking by running multiple applications simultaneously.

3.2.3 Functions of an Operating System

  • Process Management: Creating, scheduling, and terminating processes. Process scheduling algorithms determine CPU time allocation.
  • Memory Management: Allocating and deallocating memory to processes, and managing virtual memory, which allows programs to use more memory than physically available.
  • I/O Management: Handling input/output operations with device drivers.
  • File Management: Organizing and managing files and directories with file systems.

3.2.4 OS Terminology

  • Multiprogramming: Running multiple programs concurrently to increase CPU utilization.
  • Multitasking: Switching between tasks rapidly to give the illusion of parallel execution.
  • Multiprocessing: Using multiple CPUs to execute tasks in parallel for improved performance.
  • Distributed Systems: Multiple computers working together as a single system, offering fault tolerance and scalability.

3.3 Windows Operating System

3.3.1 Introduction to GUI-Based OS

Windows is a widely used GUI-based OS known for its user-friendly interface, making computers accessible to a broader audience.

Main Features:

  • User-friendly interface with drag-and-drop functionality.
  • Easier file management using File Explorer.
  • Simplified customization options for desktop and start menu.

Working in Desktop Applications

This includes managing files, folders, and using applications within the Windows environment. Key aspects include:

  • Manage Files/Folders: Use File Explorer for organizing files (creating, deleting, renaming).
  • Customize Desktop: Change themes, wallpapers, screen savers, and taskbar settings.
  • Add/Remove Devices: Install or uninstall hardware drivers and configure devices.
  • Password Management: Secure accounts with passwords and privacy settings, and manage user accounts.
  • Control Panel Tools: Manage system settings like time, network, and user accounts.
  • Windows Registry and Windows Services are also important concepts.

3.4 Open Source & Mobile OS

Concept of Open Source OS

An open-source OS allows users to view, modify, and distribute its source code, fostering collaboration and innovation.

Introduction to Linux & UNIX

Linux: A free and open-source OS known for its stability and security, widely used in servers and embedded systems.
UNIX: A powerful multiuser OS used in enterprise systems and servers.

Concept of Mobile OS

A mobile OS powers smartphones and tablets, optimizing performance and battery life, and managing touch screen input and cellular network connectivity.

  • Android: Open-source mobile OS by Google, known for flexibility and customization.
  • iOS: Proprietary mobile OS by Apple, known for user-friendliness and security.
  • KaiOS: Lightweight OS for feature phones, providing internet access and basic apps.
